Tend privacy policy

← Tend

Tend is a private, self-hosted health tracker run by an individual for personal and household use. It is not a public service.

What data Tend reads

If the user chooses to connect their Google account, Tend requests read-only access to: sleep; activity and fitness (such as workouts and steps); and health metrics and measurements (such as resting heart rate, heart rate variability and weight), through the Google Health API. Tend also stores what the user types in themselves (mood, notes, habits, gym sessions).

Where it goes

The data is stored only on the user's own server, in a database that Tend controls. It is not sold, not shared with third parties, not used for advertising, and not used to train AI models. A person at the app's operator can read it only if they are the same person as the user, or someone the user shares access with.

Google API Services User Data Policy

Tend's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Your control

The user can disconnect Google inside Tend at any time, or remove Tend's access at myaccount.google.com/permissions. Disconnecting stops all further reading. Data already stored can be exported or deleted from within Tend.
