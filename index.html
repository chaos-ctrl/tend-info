Tend

Tend is a small personal health tracker that I run on my own home server. It brings together sleep, mood, workouts and habits so I can see how they connect.

It is a private, self-hosted app for personal use by me and my household. It is not a public service and has no public sign-up.

To read my own Pixel Watch data, Tend asks Google for read-only access to sleep, activity and fitness, and health metrics (such as heart rate and weight), using the Google Health API. The data goes only to my own server.
